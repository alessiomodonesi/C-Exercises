HEADER FORWARED
===============
Nella richiesta HTTP generata verso il server remoto, il proxy deve aggiungere
l'header "Forwarded", come definito nella RFC 7239.

L'header deve  contenere esclusivamente il parametro "for", il cui valore deve
identificare l'indirizzo IP del client che ha originato la richiesta.
Non e' richiesto implementare gli altri parametri previsti dalla RFC 7239.
La sintassi dell'header deve essere conforme alla RFC 7239. (v. RIFERIMENTI)

GESTIONE DEGLI ERRORI DI CONNESSIONE
====================================

Il proxy  deve  rilevare  gli errori che si verificano durante il  tentativo di
connessione TCP verso il server remoto.
Se il  tentativo di connessione  fallisce a causa di  un timeout, il proxy deve
restituire al client una risposta HTTP avente codice di stato 504.
Per  qualunque altro  errore  di  connessione, il  proxy  deve  restituir e una
risposta HTTP avente codice di stato 502.
Entrambe le risposte devono essere  HTTP correttamente formate  e contenere una
breve pagina HTML che descriva l'errore.
La sintassi delle risposte deve essere conforme alla RFC 9110 (v. RIFERIMENTI)
